# RayWare

**Roblox scripting, interfaces, and tools.**

RayWare is an independent Roblox development identity focused on Lua scripts, practical utilities, and clean user interfaces. The goal is to make tools that feel polished, responsive, and easy to use on both desktop and mobile.

## Projects

### SerpentUI
A Roblox Lua UI library built around a consistent visual style, smooth animations, customizable themes, and mobile-friendly controls. Designed as a reusable foundation for other scripts.

[Explore SerpentUI](https://github.com/rayware/SerpentUI)

### SerpentHub — DOORS
A DOORS utility script featuring visual highlights for entities, doors, and items, plus gameplay alerts and display options.

[View source](https://github.com/rayware/Serpent-doors)

### Auto Clean
A compact utility script with a minimal interface, simple controls, theme options, and animated window interactions.

[View source](https://github.com/rayware/dig-and-clean)

### MM2 Scripts
Roblox Murder Mystery 2 scripting projects, including role-based visual indicators and related utilities.

[Explore MM2 repository](https://github.com/rayware/mm2)

### Other Roblox Experiments
RayWare has also explored aiming utilities, flight controls, and lightweight script interfaces. Check the GitHub profile for projects and releases that are publicly available.

## Design Principles

- **Minimal by default:** clear layouts without unnecessary clutter.
- **Smooth interactions:** polished transitions and responsive controls.
- **Desktop and mobile:** interfaces designed for different screen sizes.
- **Reusable components:** shared UI patterns across projects.
